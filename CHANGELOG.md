# Changelog

## 1.0.0 - 2026-06-11
### Added
- Initial release
- `/wallpaper-setup` guided install with background, font scale, and auto-update options
- `/wallpaper-update` manual wallpaper refresh command
- `/wallpaper-remove` uninstall and cleanup command
- Three bundled dark background presets: dark-mesh, deep-space, carbon
- Auto-update daemon support: launchd (macOS), systemd (Linux), Task Scheduler (Windows)
- Gradient fallback background when no image is configured
